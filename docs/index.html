BGM Uploader

個人の YouTube チャンネル運営のための、非公開の内部ツールです。

概要

BGM Uploader は、運営者が自分で制作した作業用BGM動画を、運営者自身の YouTube チャンネルへアップロードするためのツールです。 運営者のPC上でのみ動作し、第三者への提供や一般公開は行っていません。

  • 運営者が制作した動画を、運営者の承認後に YouTube Data API でアップロードします。
  • 使用する権限は動画のアップロード（youtube.upload）のみです。
  • 他のユーザーのアカウントやデータにはアクセスしません。

About (English)

BGM Uploader is a private, internal tool used by a single channel owner to upload their own background-music videos to their own YouTube channel via the YouTube Data API. It runs only on the owner's computer, is not offered to other users, and requests only the youtube.upload scope.
