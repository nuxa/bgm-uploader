プライバシーポリシー

最終更新日: 2026年11月17日

BGM Uploader（以下「本ツール」）は、運営者が自身の YouTube チャンネルに動画をアップロードするための内部ツールです。本ツールは YouTube API Services を使用しています。

1. 取得する情報

本ツールは、Google の OAuth 認証を通じて、YouTube への動画アップロード権限（https://www.googleapis.com/auth/youtube.upload）のみを取得します。氏名、メールアドレス、視聴履歴、その他の個人情報を取得・閲覧することはありません。

2. 情報の利用目的

取得した認証情報は、運営者が承認した動画を運営者自身の YouTube チャンネルへアップロードし、そのサムネイルを設定する目的にのみ使用します。

3. 保存と管理

認証トークンは運営者のPC内にのみ保存され、外部のサーバーへ送信・保存することはありません。

4. 第三者への提供

取得した情報を第三者に販売・共有・提供することはありません。

5. アクセス権の取り消し

本ツールに付与したアクセス権は、Google アカウントのセキュリティ設定ページからいつでも取り消すことができます。

6. YouTube と Google のポリシー

本ツールは YouTube API Services を使用しています。本ツールを利用することで、YouTube 利用規約に同意したものとみなされます。Google による情報の取り扱いについては、Google プライバシーポリシーをご確認ください。

Privacy Policy (English)

Last updated: November 17, 2026

BGM Uploader ("the Tool") is an internal tool used by its operator to upload videos to the operator's own YouTube channel. The Tool uses YouTube API Services.

1. Information accessed

Through Google OAuth, the Tool requests only the YouTube upload scope (https://www.googleapis.com/auth/youtube.upload). It does not access names, email addresses, watch history or any other personal data.

2. How information is used

The credentials are used solely to upload operator-approved videos, and set their thumbnails, on the operator's own YouTube channel.

3. Storage

OAuth tokens are stored only on the operator's local computer and are never transmitted to or stored on any other server.

4. Sharing

No information is sold, shared or disclosed to third parties.

5. Revoking access

Access can be revoked at any time via the Google security settings page.

6. YouTube and Google policies

The Tool uses YouTube API Services. By using the Tool you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.
